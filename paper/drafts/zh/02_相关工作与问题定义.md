# 2. 相关工作与问题定位

## 2.1 化学信息抽取与知识图谱

化学信息抽取需要表示的不只是命名实体。一条有用的记录可能包括材料身份、组成、合成或操作条件、带单位和区间的测量值、比较对象，以及报告的性质或性能结果。同一个概念可能以缩写、拼写变体、商品名、不同单位约定或依赖上下文的关系短语出现。因此，仅存储实体字符串和一个通用关系的知识表示，可能会合并本应保持区分的提及，或者使测量值脱离其产生时所对应的条件。

知识图谱为实体和关系索引提供了实用抽象，化学知识图谱系统已经支持搜索、预测和面向合成的应用。其常见表示是由类型化实体和成对边组成的集合。这种表示对于许多任务都很有价值，尤其适用于事实天然为二元关系的情况，或以图遍历为主要操作的情况。然而，对于本文研究的检索问题，一次化学观测可能受到两个以上参与者以及附加测量值和条件的联合约束。挑战在于：在支持高效匹配和源级核查的同时，保留这种作用范围。

HyperChE 将归一化视为表示方式的一部分，而不是事后进行的表面处理。规范化形式支持跨别名、关系变体、单位和数值形式的聚合与检索；表面形式和证据指针仍然可用于引用、审计以及重建原始论断。测量实例和条件实例被表示为事实记录中的角色，从而避免将来自不同实验设置的数值悄然转换为无条件属性。

## 2.2 检索增强生成与图增强检索

标准检索增强生成（retrieval-augmented generation, RAG）通常索引文档文本块，并将排名靠前的段落提供给语言模型。这种设计简单且保留了局部行文，但文本块是粗粒度的检索单元：它可能包含多个事实，可能遗漏位于相邻文本块中的条件，也可能返回一个短语，却没有显式呈现将该短语与问题连接起来的关系。在查询/文本块相关性协议下，文本块检索也可能具有很强的竞争优势，因为直接返回的文本块已经包含答案文字。

图增强 RAG 引入实体、关系、社区或路径等额外的检索与推理结构。GraphRAG 及其后续系统使用图构建、实体检索、图扩展或基于路径的排序来改善大规模语料的组织。其他系统针对特定领域专门设计图接口，或将图证据与文本块检索结合。这些方法表明，结构化检索可以补充传统 RAG 的局部上下文。

HyperChE 关注的关键区别在于检索单元和证据组装操作。成对图暴露局部边和邻域；超图暴露属于同一个 n 元事实的一组实体和角色，使实体匹配可以扩展到完整事实，或者使事实匹配可以展示其全部成员。因此，HyperChE 使用混合检索生成候选，但评价的是返回证据是否支持完整的已接受事实，而不只是某个局部短语是否相关。

## 2.3 超图知识表示

标准图通常写作

\[
G=(V,E),
\]

其中 $V$ 是实体集合，$E$ 中的每条边连接两个端点。成对事实可以用端点元组 $V_e=(v_h,v_t)$ 表示。超图将这一结构推广为

\[
G_H=(V,E_H),
\]

其中每条超边 $e_H\in E_H$ 连接两个或更多实体：

\[
V_{e_H}=(v_1,v_2,\ldots,v_n),\qquad n\geq 2.
\]

相应的 n 元事实为

\[
F_n=(e_H,V_{e_H})\in G_H.
\]

$n=2$ 的情形包含普通边这一特殊情况。这种推广的意义不只是增加边的数量，而是改变了可以被存储、检索、扩展和核查的单元：一条超边能够表示多个实体在同一个事实中的联合归属。HyperGraphRAG 论文先以一个具体事实的三种形式——文本块文本、二元图边和一条超边——直观展示成对分解造成的绑定损失，然后给出上述定义。该论文随后构建知识超图，检索实体和超边，双向扩展检索到的结构，并将恢复的事实与文本块证据结合起来。

这种说明顺序对于化学应用很有帮助。读者应先看到一个材料—组分—条件—测量—结果记录，以及它如何被成对边拆散；随后，形式化定义再说明所提出的超边保留了什么。实现层面可以使用二部关联图或其他数据库结构存储；只要超边成员关系被无损保留，这种存储选择本身并不会将语义表示降为二元事实。

既有超图表示和超关系嵌入工作往往侧重链接预测、节点分类或表示学习。HyperChE 处理的是另一种操作目标：为化学实验问题检索有来源依据的证据。因此，核心测量是检索排序和完整事实覆盖；QA 则作为补充检查，用于判断检索到的证据是否能够支持生成答案。

## 2.4 化学 RAG 系统的评价

评价选择会影响系统看起来擅长检索什么。文本块级 qrels 对冻结的检索单元进行相关性审计很有用，但会奖励返回目标措辞所在文本块的系统。它不一定能衡量系统是否恢复了多部分化学事实的全部组成，或是否跨文本块组合了证据。由文本块标签推导出的源级计数可以诊断结果的集中程度和多样性，但它不是独立的源级金标准。生成答案指标可以评价正确性、完整性、拒答和引用行为，但也依赖生成模型及服务条件。

HyperChE 报告多个视角，以区分这些影响。Hit@5、MRR 和共享 gNDCG@5 根据共同的查询/文本块判定衡量排序。Composite Fact Recall 要求已接受原子事实的精确支撑文本块出现在 top-5 中，因此测试的是更严格的证据覆盖形式。来源多样性统计作为诊断指标报告，并由相同的检索输出推导。QA 指标属于补充结果：历史组和 F1 使用不同的服务商，即使名义上的模型名称相同，因此这些结果不会被呈现为完全受控的五组生成排序。

## 2.5 问题定位与研究范围

HyperChE 位于化学信息抽取、图增强 RAG 和超图知识表示的交叉位置。本文将三个容易混在一起的设计问题分开考察：化工领域提示词是否是构建有效结构的必要条件；归一化是否能提高检索质量和完整事实召回；最终配置的优势究竟来自事实表示、候选组织还是后续排序。因此，本文考察由领域提示、归一化、测量/条件建模、规范形式/表面形式可追溯性以及实体—超边检索共同组成的流程，是否能在共享协议下改善高阶证据恢复。

保留的实验提供了五种系统视图：原始超图（B0）、化学提示成对图（B1）、未经归一化的化学提示超图（B2）、无重排的归一化超图（F0）以及带确定性重排的归一化超图（F1）。由于 B1 和 B2 的检索入口、配额、候选顺序和超边文本化并不严格相同，因此两者的差异被解释为系统级诊断，而不是单个模块的因果消融。F0/F1 比较则更窄：两个系统使用相同的混合 RRF top-50 候选池，区别仅在于候选生成之后是否启用重排开关。

这一范围带来三个实践结论。第一，化工提示词的作用必须相对于原始抽取流程进行检验，不能预先假定其必然有效。第二，归一化应与仅使用提示词的系统比较，并同时使用排序指标和 Composite Fact Recall 评价。第三，最终组的优势应拆分为事实表示、候选组织/召回和候选生成后的排序作用；仅有超图结构并不能保证质量。本文其余部分将在问题定义、方法、实验和局限性中遵循这一划分。
