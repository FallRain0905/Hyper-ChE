## 统一口径

- 题目暂定：HyperChE：面向化工高阶事实的归一化超图检索。
- 主组：B0 原始超图、B1 化学 prompt 二元图、B2 化学 prompt 超图、F0 归一化超图（无 rerank）、F1 归一化超图。
- 数据：60 篇文献、1,328 个 chunks、58 个查询、4,196 个 query/chunk 判断、150 个 accepted atomic facts。
- 主结果：F1 grade≥2 Hit@5=0.6724、MRR=0.4684、shared gNDCG@5=0.3873、CFR@5=0.4267。
- 不把 B1/B2 写成严格单变量实验；不把所有超图都宣称优于二元图。
- QA 历史组使用 Moonshot，F1 使用阿里云 DashScope；服务条件不同。
