# HyperChE LaTeX source

Compile `hyperche_arxiv.tex` from this directory using PDFLaTeX (two passes).
The main file imports `hyperche_arxiv_body.tex`, the embedded bibliography in
`references.bbl`, and the two PDF figures under `figures/`.

This is a manuscript draft using the standard LaTeX `article` class. arXiv does
not prescribe a universal visual template. The author's information is still
`Anonymous Authors`; three method/example figures remain to be drawn and added.
Do not submit this draft before completing these items.

For source submission, include the main TeX file, body, `references.bbl`, and
the actual figure PDFs. Do not include this README or generated `.aux`, `.log`,
`.out`, or the compiled manuscript PDF. Figure PDFs are required source assets.
