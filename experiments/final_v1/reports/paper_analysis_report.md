# HyperChE 论文实验结果分析报告（paper_database_v1）

## 1. 论文主线与分析边界

本文的主线是：**化工领域知识包含多实体、条件、测量值和高阶组合关系，超图结构比只表达二元关系的结构更适合承载这类知识。**

本报告按论文写作策略只保留五组主分析：

| 编号 | 系统 | 作用 |
|---|---|---|
| B0 | `original_hypergraph` | 原始超图基线 |
| B1 | `chem_prompt_graph` | 化学 prompt 二元图对照 |
| B2 | `chem_prompt_hypergraph` | 化学 prompt 原始超图对照 |
| F0 | `normalized_final_no_rerank` | 归一化、measurement、dual_concat，关闭 rerank |
| F1 | `normalized_final` | 最终归一化超图系统，开启确定性 rerank |

`chunk rerank` 与 `hybrid text baseline` 不进入论文主表、主图和主结论。原因是当前评价以 query/chunk 相关性为核心，直接返回文本块的系统具有结构性优势。两组原始结果仍保留在完整实验目录，后续可使用统一的 source-level 和 composite-evidence 口径重新评估。

## 2. 数据和评价协议

- 60 篇文献，1,328 个 frozen chunks。
- 58 个检索查询。
- 4,196 个 query/chunk 对全部完成判定，没有未判定项。
- 共享 IDCG：每个查询从完整候选并集中计算，所有保留系统使用同一分母。
- 主检索指标为 grade≥2 的 P@1、Hit@5、MRR 和 shared gNDCG@5。
- Composite Fact Recall 使用 150 个用户接受的 atomic facts，并要求 Top-5 中出现确切支持 chunk。
- embedding 为 `Qwen/Qwen3-Embedding-4B`，2560 维。
- EFU repair 全程关闭。
- 最终缓存包含 11,950 个实体、13,629 条关系，保留 14,676 个 evidence instances 的重写审计。

qrels 等级分布为 grade 0/1/2/3 = 3698/294/81/123。5 个查询没有可用 IDCG，论文脚注中应说明这些查询按当前实现的零分母规则处理。

## 3. 主检索结果

### 3.1 grade≥2 主表

| 系统 | P@1 | Hit@5 | MRR | gNDCG@5 |
|---|---:|---:|---:|---:|
| B0 原始超图 | 0.189655 | 0.482759 | 0.283206 | 0.177880 |
| B1 化学 prompt 图 | 0.275862 | 0.620690 | 0.409134 | 0.312238 |
| B2 化学 prompt 超图 | 0.224138 | 0.448276 | 0.319448 | 0.232940 |
| F0 归一化超图无 rerank | 0.327586 | 0.655172 | 0.468301 | 0.384240 |
| F1 归一化超图 | 0.327586 | 0.672414 | 0.468397 | 0.387291 |

F1 的 grade≥3 Hit@5 为 0.568966，F0 为 0.551724，B1 为 0.534483，B2 为 0.379310，B0 为 0.362069。更严格的相关性阈值下，F1 仍保持最高的保留组 Hit@5。

### 3.2 论文可用的比较

**F1 相对 B0：**

- Hit@5 从 0.482759 提升到 0.672414，增加 18.97 个百分点。
- MRR 从 0.283206 提升到 0.468397，增加 0.185191。
- gNDCG@5 从 0.177880 提升到 0.387291，增加 0.209411。
- 这说明最终归一化超图系统明显改善了原始超图的检索质量。

**F1 相对 B1：**

- Hit@5 增加 5.17 个百分点。
- MRR 增加 0.059263。
- gNDCG@5 增加 0.075053。
- 这是支持“面向化工高阶组合知识的超图表示具有价值”的最直接保留组对照。

**F1 相对 B2：**

- Hit@5 增加 22.41 个百分点。
- MRR 增加 0.148949。
- gNDCG@5 增加 0.154351。
- B2 的结果表明，单纯使用未经归一化的化学超图并不足以获得稳定收益；实体归一化、measurement 结构和 dual_concat 是最终系统的重要组成部分。

需要在论文中准确表述：B2 与 F0/F1 使用的索引和表示管线不同，因此 B2→F1 的差值是**完整系统级差异**，不能单独归因于某一个模块。

## 4. Composite Fact Recall

| 系统 | 支持 facts / 150 | CFR@5 | Macro query CFR |
|---|---:|---:|---:|
| B0 原始超图 | 14 | 0.093333 | 0.196296 |
| B1 化学 prompt 图 | 50 | 0.333333 | 0.321296 |
| B2 化学 prompt 超图 | 24 | 0.160000 | 0.201058 |
| F0 归一化超图无 rerank | 64 | 0.426667 | 0.432407 |
| F1 归一化超图 | 64 | 0.426667 | 0.432407 |

F1 相对 B0 多支持 50 个 atomic facts，CFR 从 0.093333 提升到 0.426667。相对 B1，F1 多支持 14 个 facts，CFR 提升 9.33 个百分点。

CFR 比普通 Hit@5 更能反映化工问题中的多事实绑定。结果表明，最终超图系统已经比原始超图和二元图覆盖更多组合事实，但仍有 86/150 个 atomic facts 没有在 Top-5 中形成完整支持。论文应把这一点写成当前系统的明确改进方向：提升跨 chunk 证据组合和候选多样性。

## 5. F0/F1 rerank 消融

F0 和 F1 共用同一冻结 hybrid RRF top-50 候选池，只切换确定性结构 rerank：

- Hit@5：0.655172 → 0.672414，增加 1.72 个百分点。
- MRR：0.468301 → 0.468397，增加 0.000096。
- gNDCG@5：0.384240 → 0.387291，增加 0.003051。
- CFR：0.426667 → 0.426667，没有变化。

rerank 对排序边界有小幅帮助，但没有改变事实覆盖能力。论文可以将其归纳为：**主要收益来自结构化表示和候选召回，当前 rerank 只提供有限的排序微调。**

## 6. 证据多样性诊断

Top-5 平均不同来源数与重复比例如下：

| 系统 | 平均不同来源数 | 重复比例 |
|---|---:|---:|
| B0 | 3.586 | 0.283 |
| B1 | 2.897 | 0.421 |
| B2 | 3.621 | 0.276 |
| F0 | 2.103 | 0.579 |
| F1 | 2.121 | 0.576 |

F1 的 Top-5 更集中在少数来源，重复比例较高。这解释了为什么其普通检索指标上升，但 CFR 没有因 rerank 继续上升。该 source-level 表目前仍由 chunk qrels 推导，不能当作独立 source-level gold 评价；论文中应称为“来源多样性诊断”。

## 7. QA 结果与写法

F1 QA 使用 40 道题，其中 35 道可回答、5 道不可回答；生成模型为 `kimi-k2.6`，服务为阿里云 DashScope。结果为：

- Good Rate：0.25
- Satisfactory-or-Better：0.50
- Macro KPC：0.4633
- Micro KPC：0.4825
- Hallucination Rate：0.20
- False Abstention Rate：0.1714
- False Answer Rate：0
- Unanswerable Abstention Accuracy：1.0
- Citation Reference Validity：1.0
- Citation Presence Rate：0.725
- Citation Support Score：0.4649

可写成：最终系统在一半 QA 上达到满意或更好，引用指向有效率为 100%，没有出现 False Answer；但证据覆盖不足仍限制了回答完整性。

历史四组 QA 使用 Moonshot 服务，F1 使用阿里云 DashScope。虽然模型名均为 `kimi-k2.6`，服务商不同，因此 QA 结果只作为补充验证，不能写成完全受控的五组生成质量比较。

## 8. 论文最终结论建议

建议论文主结论写成：

> 化工知识中的实体、测量值、操作条件和多实体关系通常共同构成一个高阶事实。实验表明，加入实体/关系归一化、measurement instances 和 dual representation 后，超图 RAG 在共享 qrels 下同时优于原始超图和化学 prompt 二元图，在 Hit@5、MRR、gNDCG@5 与 Composite Fact Recall 上均取得更高结果。该结果支持超图作为化工高阶知识表示的有效路线。未经归一化的原始化学超图效果较弱，说明结构形式需要与规范化和证据组织机制配合。rerank 只带来小幅排序增益，后续应重点提升跨 chunk 证据召回和来源多样性。

不要写成“所有超图组都优于图组”。更准确的说法是：**经过归一化和 measurement 结构增强的最终超图系统优于本实验中的图结构对照；原始超图本身并不自动带来收益。**

## 9. 复现和限制

- 共享 qrels 已完成用户接受审核：4,196 对全部有判定；4,175 条采用 DeepSeek 审核结果，21 条 provider 失败记录保留冻结 grade。
- Atomic gold 为 150 facts / 58 queries，其中 5 个 provider-failure queries 使用了显式标注的用户接受 fallback facts。
- 259 个同 ID chunk 存在历史 base 与 chemistry cache 文本差异，按实验计划作为非阻断变量披露。
- 当前没有显著性检验或置信区间，论文不要使用“统计显著”或过强因果表述。
- EFU repair 已永久关闭，结果不包含任何 LLM repair 的贡献。
